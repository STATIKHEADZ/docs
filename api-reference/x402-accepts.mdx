This public, free endpoint returns WURK's advertised x402 resource URLs and integration guidance.

```bash
curl 'https://wurkapi.fun/.well-known/x402'
```

| Field | Meaning |
| --- | --- |
| `version` | Discovery schema version, currently `1`; this is separate from the x402 payment protocol version. |
| `resources` | Array of absolute resource URLs, including network routes and shared job actions. |
| `ownershipProofs` | Optional array of registry ownership proofs. |
| `instructions` | Integration guidance as text. |

The list can include free secret-authenticated actions. Listing a URL here does not mean every operation on that URL requires a payment.

## Schemas and workflows

Use [canonical OpenAPI](https://wurkapi.fun/openapi.json) for advertised paid POST operations and shared actions, and [x402 OpenAPI](https://wurkapi.fun/openapi-x402.json) for advertised aliases. The [public skill](https://wurkapi.fun/skill.md) links maintained commissioning, payment, store and recovery guides.

A bare social or Basic endpoint can return an example/discovery challenge. First provide the intended target, brief, counts and reward settings, then inspect that request's actual quote. A descriptor price is not authorization to spend.

## Inspect a payable challenge

An x402 v2 payable response uses HTTP `402`, a `PAYMENT-REQUIRED` header and nonempty `accepts`. Check the selected requirement's `scheme`, `network`, `asset`, atomic `amount`, `payTo` and `extra`, together with `resource` and the payment deadline. Preserve all returned metadata when signing.

For account authentication, a 402 with `accepts: []` requests a login proof and carries no payable requirement. Follow [authentication](/authentication), then retry with the required credential.

See [paid requests](/api-reference/x402-pay) for the retry target and saved-checkout rules.
