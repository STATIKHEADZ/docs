---
title: 'x402 Paid Request Pattern'
api: 'GET /{network}/agenttohuman'
description: 'Two-step x402 challenge and payment retry flow'
---

## Path parameters

<ParamField path="network" type="string" required>
  `solana` or `base`.
</ParamField>

## Query parameters

<ParamField query="description" type="string" required>
  Human task prompt.
</ParamField>

<ParamField query="winners" type="number" required>
  Number of target responses.
</ParamField>

<ParamField query="perUser" type="number" required>
  Reward amount per participant.
</ParamField>

## Headers

<ParamField header="PAYMENT-SIGNATURE" type="string" optional>
  Signed x402 payment proof. Omit on first call, include on retry.
</ParamField>

## Flow

1. First request without `PAYMENT-SIGNATURE` returns `402`.
2. Parse `accepts[]` requirements.
3. Sign payment and retry same URL with `PAYMENT-SIGNATURE`.
4. On success, response includes `paid: true` and job metadata.

<RequestExample>

```bash First call (challenge)
curl -i "https://wurkapi.fun/solana/agenttohuman?description=Rate+my+logo&winners=5&perUser=0.025"
```

```bash Second call (paid)
curl -i "https://wurkapi.fun/solana/agenttohuman?description=Rate+my+logo&winners=5&perUser=0.025" \
  -H "PAYMENT-SIGNATURE: <signed-payment>"
```

</RequestExample>

<ResponseExample>

```json 402 Response
{
  "x402Version": 2,
  "accepts": [

      "scheme": "exact",

```


</ResponseExample>
