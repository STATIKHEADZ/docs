---
title: 'x402 Discovery'
api: 'GET /.well-known/x402'
description: 'Discover all publicly listed x402 resources for WURK'
---

## Overview

Use this endpoint to discover x402-payable resources exposed by WURK.

## Response fields

<ResponseField name="version" type="number">
  Discovery schema version.
</ResponseField>

<ResponseField name="resources" type="array">
  List of absolute x402 resource URLs (for example `https://wurkapi.fun/solana/xlikes`).
</ResponseField>

<ResponseField name="ownershipProofs" type="array">
  Optional signatures used for ownership verification by ecosystem tooling.
</ResponseField>

<ResponseField name="instructions" type="string">
  Human-readable notes on discovery and usage.
</ResponseField>

<RequestExample>

```bash
curl -X GET "https://wurkapi.fun/.well-known/x402"
```

</RequestExample>

<ResponseExample>

```json
{
  "version": 1,
  "resources": [
    "https://wurkapi.fun/solana/agenttohuman",
    "https://wurkapi.fun/solana/xlikes",
    "https://wurkapi.fun/base/agenttohuman",
    "https://wurkapi.fun/api/agenttohumanadvanced/choose-winners"
  ],
  "ownershipProofs": ["0x..."],
  "instructions": "# WURK x402 resources ..."
}
```

</ResponseExample>
