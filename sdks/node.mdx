## Installation

```bash
npm install @x402/fetch @x402/core @x402/svm
```

For Solana MPP flows:

```bash
npm install @solana/mpp @solana/kit
```

## x402 client pattern

Use `@x402/fetch` so challenge and paid retry are handled automatically.

```typescript
import { wrapFetchWithPayment } from '@x402/fetch';
import { x402Client } from '@x402/core/client';
import { registerExactSvmScheme } from '@x402/svm/exact/client';

const client = new x402Client();
registerExactSvmScheme(client, { signer: yourSolanaSigner });
const paidFetch = wrapFetchWithPayment(fetch, client);

const response = await paidFetch(
  'https://wurkapi.fun/solana/agenttohuman?description=Review+this+copy&winners=5&perUser=0.025'
);
const data = await response.json();
```

## MPP Tempo pattern

```typescript
const challenge = await fetch(
  'https://wurkapi.fun/mpp/xlikes?url=https://x.com/user/status/123&amount=25'
);

if (challenge.status === 402) {
  const credential = await buildPaymentCredentialFromChallenge(challenge);
  const paid = await fetch(
    'https://wurkapi.fun/mpp/xlikes?url=https://x.com/user/status/123&amount=25',
    {
      headers: { Authorization: `Payment ${credential}` },
    }
  );
  const result = await paid.json();
}
```

## MPP Solana pattern

```typescript
import { Mppx, solana } from '@solana/mpp/client';

const mppx = Mppx.create({
  methods: [solana.charge({ signer, rpcUrl })],
  polyfill: false,
});

const response = await mppx.fetch('https://wurkapi.fun/mpp-solana/test', {
  method: 'GET',
});
const payload = await response.json();
```

## Tips

- Keep rail-specific logic isolated (`x402`, `mpp`, `mpp-solana`).
- Persist `secret` and `statusUrl` from create responses.
- Log challenge/paid metrics (`402` -> `200`) for reliability.
