---
title: 'Social Jobs'
description: 'Create social engagement jobs with native USDC on Solana or Base'
---

Social orders use `/{network}/{service}`, where `network` is `solana` or `base`. Send the intended target and quantities, inspect the returned x402 quote, and pay with `PAYMENT-SIGNATURE`. Creation does not require an API key or account login.

## Public services

| Service | Path after `/{network}/` | Target input |
| --- | --- | --- |
| X likes and views | `xlikes`, `xviews` | Post `url`. |
| X reposts, comments and bookmarks | `reposts`, `comments`, `xbookmarks` | Post `url`. |
| X followers | `xfollowers`, `xfollowers/xverified` | `handle` or profile `url`. |
| Instagram | `insta-likes`, `instacomments`, `instafollowers` | Content `url`; followers use `handle` or profile `url`. |
| YouTube | `ytlikes`, `ytcomments`, `ytsubs` | Video `url`; subscriptions use `handle` or channel `url`. |
| Telegram members | `tgmembers` | Join link using `join` or `url`, or supported `group` input. |
| DexScreener rockets | `dex` | Pair `url`. |
| CoinGecko and CoinMarketCap votes | `cgvote`, `cmcvote` | Supported coin `url`. |
| X raid packages | `xraid`, `xraid/small`, `xraid/medium`, `xraid/large`, `xraid/mega` | Post `url`; dynamic `xraid` also takes `size`. |
| X verified raid packages | `xraid/xverified`, `xraid/xverified/small`, `xraid/xverified/medium` | Post `url`. |

The unified `vote` endpoint accepts `voteType:"coingecko_vote"` or `"coinmarketcap_vote"`, `url` and `amount`. Consult [advertised x402 OpenAPI](https://wurkapi.fun/openapi-x402.json) for service-specific schemas and aliases.

## Counts and instructions

Many single-action routes accept `amount`; bounds and defaults differ by service. For example, X likes accepts 5–250, default 40; X views accepts 10–5000, default 100; X verified followers accepts 5–100, default 100. Use explicit integer counts so the request reflects the intended purchase.

Instagram and YouTube comments accept optional `instructions`. Use a canonical public target URL; a missing target can return a discovery descriptor rather than a quote for an actual job.

For custom raids, `xraid/custom` takes `url`, `likes`, `reposts`, `comments` and `bookmarks`. The verified variant is `xraid/xverified/custom`. For verified custom raids, each count is `0` or 5–100, with at least one active component. Inspect the returned package and every component; verified presets gate engagement components while views remain ungated.

## Quote and pay

```bash
curl --get --include 'https://wurkapi.fun/solana/xlikes' \
  --data-urlencode 'amount=50' \
  --data-urlencode 'url=https://x.com/example/status/1234567890'
```

Replace the example target before requesting a real quote. Inspect its exact network, asset, recipient, amount and resource before signing. Prices in schemas or examples do not replace the actual payment requirements.

A social quote commonly binds a canonical `/api/x402/jobs/{jobId}/pay` resource, or `/api/x402/base/jobs/{jobId}/pay`. Use that returned payment resource, or retry the unchanged public request with the saved proof. Preserve all identifiers, the original signed payment and any receipt. See [payment and recovery rules](/api-reference/x402-pay).

An uncertain response does not authorize another charge. A 409 can mean a similar paid job is already open; inspect the returned details before trying again. Order creation and paid status establish a funded campaign, not completed engagement or guaranteed delivery speed.
